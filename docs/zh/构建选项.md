# 构建选项

在 GitHub Actions 的 `Run workflow` 页面选择目标、桌面、显示后端和附加功能。带有桌面环境的 RootFS 面向 ARM64 Droidspaces 容器。

## 发行版与桌面支持

| 构建目标 | 基础镜像 | 可选桌面 | Anland Wayland |
| --- | --- | --- | --- |
| `Debian-13` | Debian 13 (trixie) | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next` | 支持 |
| `Ubuntu-24` | Ubuntu 24.04 | `none`、`KDE` | 不支持 |
| `Ubuntu-25` | Ubuntu 25.10 | `none`、`KDE` | 不支持 |
| `Ubuntu-26` | Ubuntu 26.04 | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next` | 支持 |
| `Fedora-43` | Fedora 43 | `none`、`KDE`、`KDE mobile`、`Anland Next` | 支持 |
| `Fedora-44` | Fedora 44 | `none`、`KDE`、`KDE mobile`、`Anland Next` | 支持 |
| `Arch` | Arch Linux ARM | `none`、`KDE`、`KDE mobile`、`Anland Next` | 支持 |

`all` 根据桌面与后端能力筛选并构建可用目标。`all-wayland` 为 KDE/KDE Mobile 构建五种 Wayland 目标；GNOME 只构建 Debian 13 和 Ubuntu 26。GNOME、KDE Mobile、Anland Next 会强制使用 `anland-wayland`。

| 桌面 | 用途与说明 |
| --- | --- |
| `none` | 仅命令行环境，适合 SSH、开发或自行安装桌面。 |
| `KDE` | KDE Plasma 桌面；可用 X11 或 Anland Wayland（依发行版）。 |
| `KDE mobile` | 面向手机屏幕和触控的 Plasma Mobile，会强制启用 Anland Wayland。 |
| `GNOME` | 仅 Debian 13、Ubuntu 26 的 Anland Wayland 构建，不支持 X11。 |
| `Anland Next` | 提供 Anland 会话、rootless Xwayland 与 mini-wm，不包含完整桌面环境；仅支持 Anland Wayland。 |

## 工作流输入

| 输入 | 可选值 / 默认值 | 说明 |
| --- | --- | --- |
| `build_target` | 发行版、`all`、`all-wayland`；默认 `Debian-13` | 选择构建目标。 |
| `custom_username` | 1–32 位字母、数字、`_`、`-`；以字母或 `_` 开头；默认 `Gold` | RootFS 普通用户名称。 |
| `desktop` | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`；默认 `KDE` | 选择桌面或命令行环境。 |
| `desktop_autostart` | `true` / `false`；默认 `true` | 安装桌面自启动服务；`none` 必须关闭。 |
| `display_backend` | `x11` / `anland-wayland` | 中文工作流默认 Wayland，英文工作流默认 X11；部分桌面会强制使用 Wayland。 |
| `PulseAudio` | `socket` / `tcp` / `none`；默认 `socket` | X11 音频转发方式；Anland 会自动设为 `none`。 |
| `enable_zh_tz` | `true` / `false` | 安装中文 locale 并设置上海时区；中英文工作流默认值不同。 |
| `enable_mesa` | `true` / `false`；默认 `true` | 添加 Snapdragon GPU/Mesa 支持。 |
| `enable_8gen2_wayland` | `true` / `false`；默认 `false` | 为相关设备设置 Turnip UBWC Wayland 修复参数。 |
| `nosnap` | `true` / `false` | 仅 Ubuntu：移除 Snap、snapd 并阻止其被 APT 重新安装；中英文工作流默认值不同。 |
| `enable_systemd257` | `true` / `false`；默认 `false` | 在旧 Android 内核场景尝试安装 systemd 257 包族；只支持 `none` 和普通 `KDE`。 |
| `enable_srf` | `true` / `false` | 安装 Fcitx5；中文工作流默认开启，英文工作流默认关闭。 |
| `enable_binfmt` | `true` / `false`；默认 `false` | 添加 binfmt 跨架构支持；当前不建议用于 Arch。 |
| `enable_yj` | `true` / `false`；默认 `true` | 增强 NAT 与 Android/Droidspaces 硬件识别。 |
| `enable_kfgj` | `true` / `false`；默认 `false` | 安装编译器、CMake、Python 等开发工具。 |
| `enable_zip` | `true` / `false`；默认 `true` | 安装常用压缩工具。 |
| `enable_docker` | `true` / `false`；默认 `false` | 在 RootFS 中安装 Docker 相关软件包。 |
| `wayland_package_repository` | 公开的 `owner/repository`；默认 `Goldzxcbug/droidspaces-package` | 指定 Anland KDE/GNOME Release 包的来源。 |

完整的 workflow 默认值可在 `.github/workflows/build-rootfs-releases.yml`（中文）和 `build-rootfs-releases-en.yml`（英文）中查看。`enable_systemd257` 属于实验性旧内核兼容选项，会增加构建时间；systemd 已为 257 或更低版本的系统会跳过安装，详见[脚本说明](../../scripts/README.md)。
